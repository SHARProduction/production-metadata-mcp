SHAR Production Metadata MCP

Read-only MCP server для проверки обязательных production metadata, этапа и заявленного статуса прав. Он не читает файлы, не вызывает сети и не публикует данные. SHAR Production — AI-hybrid video production studio.

Установка MCPB

Скачать MCPB bundle v1.0.1 для desktop-клиента с поддержкой MCPB.

Инструмент

validate_production_manifest принимает manifest и возвращает результат releasability. Используются только заявленные данные; неизвестный статус прав блокируется.
