SHAR Production Metadata MCP

A read-only MCP server for validating required production metadata, stage and declared rights status. It does not read files, call networks, or publish data. SHAR Production is an AI-hybrid video production studio.

Installable MCPB

Download the v1.0.0 MCPB bundle for an MCPB-compatible desktop client.

Tool

validate_production_manifest accepts a manifest object and returns a releasability result. Use declared values only; unknown rights are blocked.
